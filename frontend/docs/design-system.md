# 這是誰的鍋：協作工作台

本版依 PROJECT_BRIEF.md 的四個主要頁面實作。尚未確認的業務規則以示範行為呈現，不作為後端規格。

## 視覺

首頁直接開啟新增分析表單；報告以垂直 Use Case 卡片呈現，編號作為索引。

- 主文字：#243B34，次要文字需保持可讀對比。
- 主操作：#227561；背景 #F8FAF9；白色內容區 #FFFFFF。
- 淡綠協作說明區 #F0F4EA；狀態使用文字、圓點及柔和的琥珀、藍、綠區別。
- 字體：Avenir Next 搭配 PingFang TC / Microsoft JhengHei，不依賴外部字體請求。
- 桌面：固定左導覽、頂部路徑；報告上方顯示編號與名稱的橫向步驟列，下方為完整卡片。
- 手機：抽屜導覽、單欄卡片；部門標籤換行，步驟列可橫向捲動並跳至對應卡片。
- 圓角 7–12px，邊框區分結構，少量陰影僅用於浮動介面與流程節點。

## 前端示範範圍

1. 公司為固定的甩鍋科技示範工作空間，沒有登入或真正的公司隔離服務。
2. PRD 與公司文件支援 TXT / Markdown，每份最大 1 MB。公司文件可多選；不解析 PDF / DOCX。
3. 分析依固定範本產生，沒有呼叫 AI。原始 PRD 會保存，可下載。
4. 報告狀態暫採待確認、協作中、已準備開案。
5. 每個 Use Case 包含名稱、建議協作部門、說明與使用者回饋。
6. 回饋自動儲存；儲存失敗時保留輸入並顯示備份提示。
7. 使用版本化 localStorage 保存，不提供跨使用者同步或真實 global memory 推論。
8. 導覽使用 hash，配合既有靜態匯出，可重整與使用上一頁。
