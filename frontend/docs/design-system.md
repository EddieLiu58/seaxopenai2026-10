# Seax Studio 起始設計

暫定主題為數位設計工作室，面向想了解品牌與介面設計的訪客；首頁的主要工作是引導瀏覽概念作品。名稱與案例皆可替換。

- 配色：霧白 #F7F9FC、深藍 #172B49、鈷藍 #2351D8、灰藍 #52627B、淺藍 #E8EEF9、分隔線 #D8E0EB。
- 字體：Avenir Next 與系統繁中文字體；Georgia 僅用於品牌圖形。使用本機字體，建置不依賴外部字體下載。
- 排版：桌面主視覺左右分欄、作品三欄，手機轉單欄。正文靠左，限制閱讀寬度。
- 特色：以軌道包圍字母的 CSS 圖形呈現想法逐漸成形；其他區塊保持安靜。
- 檢視：技能搜尋的作品集方向適用，但黑白與大量捲動動畫不符合此繁中文起始頁，因此調整為明亮藍色系及操作回饋。
- 互動：作品篩選使用 aria-pressed；FAQ 使用原生 details；44px 操作區域、可見鍵盤焦點、跳至內容連結與減少動態設定。
